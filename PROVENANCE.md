# Upstream Provenance

Agent Fleet for Android is derived from
[`termux/termux-app`](https://github.com/termux/termux-app) tag `v0.118.3`,
commit `5b657c6adf4304e5198951ce815fe0205dcac29c`.

The repository retains upstream Git history. `origin` points to
`yaakovch/agent-fleet-android`; `upstream` points to `termux/termux-app`.
Upstream tags are merged deliberately after terminal, bootstrap, package,
migration, and privacy regression checks.

The project remains GPLv3-only, including modifications to upstream GPL code.
The Apache-2.0 and MIT exceptions already identified by upstream remain under
their respective licenses. Agent Fleet branding does not imply endorsement by
the Termux project.
